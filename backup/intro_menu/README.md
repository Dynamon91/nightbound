# Nightbound — Intro + Interactive Menu Demo V1

## Deliverables
- `Nightbound_Intro_Loop.gif`: animated 8-second loop (10 fps, 720px wide), using camera drift, soft lighting and moving motes applied to the concept image.
- `Nightbound_Intro_Cinematic.mp4`: 8-second animation (12 fps, 800x450).
- `Nightbound_Menu_Interattivo.html`: standalone Italian main menu with keyboard, mouse, effects, settings and mock browser-local save slots.
- `nightbound_title_background.png`: reference background.

## Status
Media exports were checked. This is a 2D concept-art motion treatment, **not** a rendered 3D flyover. Menu actions work only in HTML, not in Godot. Production gameplay and save integration remain to be tested.

## How to try
Open `Nightbound_Menu_Interattivo.html` in a modern browser. Use mouse/touch or ArrowUp/ArrowDown and Enter. 'Continue' only opens a demo dialog.

## Art direction
Based on the existing Nightbound concept images, without copying Spyro visual assets. Levels are intended to be wide, interconnected exploration hubs.
