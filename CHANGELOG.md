# Changelog

## v1.1 — Prototype mechanics pass

- Added collision geometry for the main floor and raised platforms.
- Added third-person movement, jump/glide and burst-charge input.
- Added crystal collection, Echosense secrets, checkpoints and save/load.
- Added prototype Gloam Warden encounter, Shadow Dash unlock, Lira quest and Memory Orbs.
- Documented controls and verification limitations.

## Known limitations

- No Godot runtime/build verification has been completed in this environment.
- Gameplay balance, input behavior, collision edge cases and save/load need testing in Godot 4.x.
- The concept preview is illustrative, not a live game capture.
