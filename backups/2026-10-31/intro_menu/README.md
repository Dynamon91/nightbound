# Nightbound — Intro + Interactive Menu Demo V1

## Deliverables
- `Nightbound_Intro_Loop.gif`: animated 8-second loop (10 fps, 720px wide). Camera drift, soft lighting and moving motes applied to the concept image.
- `Nightbound_Intro_Cinematic.mp4`: same animation as an MP4 video (12 fps, 800x450).
- `Nightbound_Menu_Interattivo.html`: standalone Italian main menu with keyboard, mouse, effects, settings, and mock save slots stored in localStorage. Does not require a server.
- `nightbound_title_background.png`: source reference background used by the menu.

## Status
Real exports verified via media tools. Animation is a 2D concept-art motion treatment, **not** a rendered 3D camera flight; the character's wing animation has not been rendered. Menu actions work only inside the HTML demonstration. Godot project integration and production gameplay still need to be implemented and tested.

## How to try
Open `Nightbound_Menu_Interattivo.html` in a modern browser. Use mouse/touch or ArrowUp/ArrowDown and Enter. Save slots are browser-local, and 'Continue' only opens a demo dialog.

## Art direction
Uses the existing Nightbound concept images; avoids copying Spyro visual assets or animation. The level goal remains wide, interconnected, exploratory hub levels.
